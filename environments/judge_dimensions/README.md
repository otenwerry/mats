# Environment judge dimensions

These are the active source texts for the environments-owned structured judge. The
judge code loads the files in a fixed order; Markdown explains each concept, while
`lib/environment_judge/schema.py` defines the stored output types.

This directory does not use Petri's 1–10 dimension format. Binary answers are booleans,
no reward hack is an empty type list, and ML deception is null when no hack occurred.
